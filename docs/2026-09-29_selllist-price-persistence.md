# Selllist 가격 수정 유지

- 발견: Peter 판매의 `list_price > 1000`, `price === list_price` 조건에서 판매 목록 조회가 20% 할인 가격을 DB에 다시 기록했다. 관리자가 정상가로 수정한 경우 재조회 시 덮어써질 수 있었다.
- 변경: 목록 조회의 자동 가격 보정을 제거했다. 판매 생성 및 명시적 가이드 변경 시 할인 적용은 유지한다.
- 변경: 가격 수정 PATCH의 반환 행과 가격을 확인하여 0건 수정 또는 요청 가격과 다른 저장 결과를 성공 처리하지 않는다. DB 구조/API 입력·출력 계약 변경은 없다.
- 검증: `node --test tests/sale-price-persistence.test.mjs` 3개 통과. 모의 DB로 반복 조회 시 가격·합계 유지, 저장 0건/가격 불일치, 교환 호환 경로 실패를 확인했다.
- 한계: 연결된 Supabase 도구에 해당 프로젝트가 없어 실제 신고 건과 운영 DB의 저장 후 새로고침은 미확인. 배포하지 않았다.
