# Royal Golf `/guides` 정산 버튼 추가 수정

이 문서는 이번에 새로 요청한 내용만 포함한다.

## 1. `Edit Points` 제거

`/guides` 목록의 모든 행에서 `Edit Points` 버튼을 완전히 제거한다.

```text
제거: Edit Points
```

- 일반 가이드에서 제거
- 로컬 가이드에서 제거
- 커미션 제외 대상에서도 제거
- 버튼만 숨기는 것이 아니라 해당 화면에서 Edit Points 모달을 여는 동작과 연결도 제거

## 2. `정산 완료` 명칭 변경

기존 `정산 완료` 버튼의 표시 이름을 `전체 정산`으로 변경한다.

```text
기존: 정산 완료
변경: 전체 정산
```

- 버튼의 기존 전체 정산 기능은 유지한다.
- 버튼의 빨간색 스타일은 유지한다.
- 모달 제목, 확인 버튼, 안내 문구에도 `정산 완료`가 남아 있으면 모두 `전체 정산`으로 통일한다.

## 3. 일반 가이드 Action

커미션 대상 일반 가이드의 `Action`에는 다음 두 버튼만 표시한다.

```text
[ 부분 정산 ] [ 전체 정산 ]
```

- `Edit Points`는 표시하지 않는다.
- Balance가 0보다 크면 두 버튼을 활성화한다.
- Balance가 0 이하이면 두 버튼은 표시하되 비활성화한다.

## 4. 로컬 가이드 Action

로컬 가이드에도 일반 가이드와 동일하게 다음 두 버튼을 반드시 표시한다.

```text
[ 부분 정산 ] [ 전체 정산 ]
```

- 로컬 가이드라는 이유로 정산 버튼을 숨기지 않는다.
- Balance가 0보다 크면 두 버튼을 활성화한다.
- Balance가 0 이하이면 두 버튼은 표시하되 비활성화한다.
- `부분 정산`은 기존 부분 정산 기능을 사용한다.
- `전체 정산`은 현재 Balance 전액을 정산하여 Balance를 0으로 만드는 기존 기능을 사용한다.

## 5. 최종 표시 예시

| Type | Balance | Action |
|---|---:|---|
| Guide | 1,050 | `부분 정산` · `전체 정산` |
| Guide | 0 | 비활성화된 `부분 정산` · `전체 정산` |
| Local Guide | 500 | `부분 정산` · `전체 정산` |
| Local Guide | 0 | 비활성화된 `부분 정산` · `전체 정산` |

## 6. Mr.Moon 목록 제외

Mr.Moon은 커미션과 정산 대상이 아니므로 `/guides` 목록에서 완전히 제외한다.

- `All` 목록에서 제외
- `Guide` 필터 목록에서 제외
- 이름 정규화 후 `mrmoon`과 일치하면 조회 결과에서 제외
- 화면에서만 제외하며 기존 판매 및 할인 데이터는 변경하지 않는다.

```js
const normalizeName = (name) =>
  String(name || '').toLowerCase().replace(/[\s.]/g, '');

const visibleGuides = guides.filter(
  (guide) => normalizeName(guide.name) !== 'mrmoon'
);
```

## 7. 부분 정산 모달 높이 및 닫기 버튼 수정

부분 정산 모달의 확인 버튼 아래에 표시되는 `Close` 버튼을 완전히 제거한다.

```text
제거: Close
유지: 우측 상단 X 버튼
```

- 모달을 닫는 UI는 우측 상단 빨간색 `X` 버튼 하나만 사용한다.
- `부분 정산 확인` 버튼 바로 아래에서 모달 콘텐츠가 끝나야 한다.
- 확인 버튼 아래에는 별도 Footer, 닫기 버튼 또는 빈 컨테이너를 렌더링하지 않는다.
- `Close` 버튼을 CSS로만 숨기지 말고 JSX에서 제거한다.

모달 크기 기준:

```css
.partial-settlement-modal {
  width: min(420px, calc(100vw - 32px));
  height: fit-content;
  min-height: unset;
}

.partial-settlement-modal__content {
  display: flex;
  flex-direction: column;
  gap: 12px;
  padding: 20px;
}
```

- 부모 모달에는 별도의 상단·하단 여백이나 고정 높이를 지정하지 않는다.
- 부모 모달의 크기는 자식 콘텐츠의 실제 크기만큼만 생성한다.
- 여백은 부모 높이로 만들지 않고 자식 콘텐츠 컨테이너의 공통 `padding`으로만 처리한다.
- 상단과 하단에 별도 `padding-top`, `padding-bottom` 값을 추가하지 않는다.
- 기존의 고정 `height`, 큰 `min-height`, `flex: 1`을 모두 제거한다.
- `justify-content: space-between`과 빈 Footer 컨테이너를 사용하지 않는다.
- 입력한 금액에 따라 `실제 지급액` 카드가 나타나면 자식 콘텐츠가 늘어난 만큼 부모 모달도 자연스럽게 늘어난다.
- 화면 높이를 초과하는 작은 화면에서만 미디어 쿼리로 `max-height`와 `overflow-y: auto`를 적용한다.

정상 구조:

```text
[ 부분 정산: MACHADO              X ]
[ Guide / Rate                       ]
[ Current Balance                    ]
[ 정산 후 남길 Balance 입력          ]
[ 실제 지급액                        ]
[          부분 정산 확인            ]
모달 끝
```

## 8. 완료 기준

- [ ] `/guides`에서 `Edit Points` 버튼이 모두 제거된다.
- [ ] `정산 완료`라는 버튼명이 `전체 정산`으로 변경된다.
- [ ] 일반 가이드에는 `부분 정산`과 `전체 정산`만 표시된다.
- [ ] 로컬 가이드에도 `부분 정산`과 `전체 정산`이 표시된다.
- [ ] Balance가 0인 일반·로컬 가이드도 두 버튼이 보이지만 비활성화된다.
- [ ] 커미션 제외 대상에는 정산 버튼이 표시되지 않는다.
- [ ] Mr.Moon은 `/guides`의 모든 목록과 필터에서 제외된다.
- [ ] 부분 정산과 전체 정산의 기존 저장 및 정산 기능은 그대로 유지된다.
- [ ] `부분 정산 확인` 아래의 `Close` 버튼이 제거된다.
- [ ] 모달은 우측 상단 `X`로만 닫을 수 있다.
- [ ] 부분 정산 모달의 고정 높이와 불필요한 하단 빈 공간이 제거된다.
- [ ] 실제 지급액 카드 표시 여부에 따라 모달 높이가 콘텐츠에 맞게 자동 조정된다.
- [ ] 부모 모달은 자식 콘텐츠 크기만큼만 생성된다.
- [ ] 모달 내부 여백은 자식 콘텐츠 컨테이너의 공통 패딩으로만 처리된다.
