# 가이드 미정산 판매내역 기반 정산 기능 개선

## 목적

`/guides`의 기존 가이드별 커미션 총액 중심 정산 방식을 변경하여, **아직 정산되지 않은 판매 건을 개별적으로 확인하고 선택하여 정산**할 수 있도록 개선한다.

## 핵심 기능

- 가이드별 미정산 판매내역만 조회
- 판매 건별 체크박스로 부분 정산
- `전체 정산` 클릭 시 모든 미정산 건 자동 선택
- 판매일 / 상품코드 / 판매금액 / 커미션율 / 커미션 금액 표시
- 선택된 판매 건 기준 총 판매금액 및 총 커미션 금액 표시
- 커미션율은 가이드 유형에 따라 `10%` 또는 `20%`
- 정산 완료된 판매 건은 미정산 목록에서 제거

## 판매내역 테이블

| 선택 | 판매일 | 상품코드 | 판매금액 | 커미션율 | 커미션 금액 |
|---|---|---|---:|---:|---:|
| ☐ | 2026-08-15 | PROD-001 | 1,000 | 10% | 100 |
| ☐ | 2026-08-16 | PROD-023 | 2,000 | 20% | 400 |

커미션 금액:

`판매금액 × 커미션율`

## 부분 정산

관리자가 원하는 판매 건만 체크한 후 `선택 정산`을 실행한다.

- 선택한 건만 정산 완료 처리
- 선택하지 않은 건은 미정산 상태 유지
- 정산 완료된 건은 미정산 목록에서 제거
- 하단 합계는 현재 선택된 건을 기준으로 계산

## 전체 정산

`전체 정산` 버튼을 누르면 해당 가이드의 모든 미정산 판매 건을 자동으로 체크한다.

이후 전체 미정산 판매내역의:

- 총 판매금액
- 총 커미션 금액

을 확인한 후 정산할 수 있도록 한다.

## 하단 합계

```text
선택된 건수: 3건
총 판매금액: 4,500
총 커미션 금액: 650

[선택 정산]
```

## 정산 상태

판매내역은 최소 다음 상태를 구분한다.

- `미정산`
- `정산 완료`

정산 실행 시 선택된 판매 건에 대해서만 정산 완료 상태와 정산 처리 시각을 기록한다.

## 검증

- [ ] 가이드별 미정산 판매내역만 조회된다.
- [ ] 판매일, 상품코드, 판매금액, 커미션율, 커미션 금액이 표시된다.
- [ ] 판매 건별 부분 정산이 가능하다.
- [ ] 전체 정산 시 모든 미정산 건이 자동 선택된다.
- [ ] 총 판매금액과 총 커미션 금액이 선택 건 기준으로 계산된다.
- [ ] 10% / 20% 커미션율이 올바르게 적용된다.
- [ ] 부분 정산에서 선택하지 않은 건은 미정산 상태로 유지된다.
- [ ] 정산 완료된 건은 미정산 목록에서 제거된다.
- [ ] 동일 판매 건이 중복 정산되지 않는다.
- [ ] 기존 판매 이력의 `guide_id` 연결 관계가 유지된다.
